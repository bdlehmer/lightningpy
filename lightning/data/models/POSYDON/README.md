# Custom POSYDON Cloudy Models
---

Experimental grid of models built from POSYDON and Cloudy
The stellar models are under development and will be presented 
in Kasdagli et al. (in prep).

Files you should put in this folder
```
POSYDON_fullgrid_g_binary.h5
POSYDON_fullgrid_g_single.h5
```

## Cloudy Configuration

Electron density: lognH = [2,3.5]
Not a free parameter, but can be selected with the `lognH` keyword.

ionization parameters, logU = [-1.5,-2.0,-2.5,-3.0,-3.5,-4.0]

grains : off

Currently using solar metallicity but will later replace with additional values

Open geometry
